# Task Management API

## Project Overview

The Task Management API is a robust backend service built with Node.js, Express, and TypeScript that provides complete task and user management functionality. This API allows developers to build applications where users can create, update, track, and manage tasks with proper authentication and authorization.

**Key Features:**
- User registration and authentication with JWT tokens
- Complete CRUD operations for tasks
- Role-based access control (Admin vs Regular users)
- Secure file uploads for task attachments
- Real-time notifications
- Comprehensive API documentation

**Why it's useful:** This API serves as a foundation for building task management applications like Todo lists, project management tools, or productivity apps. It handles all the backend complexity so frontend developers can focus on building great user experiences.
